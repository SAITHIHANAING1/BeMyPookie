# Be My Pookie?

A fun, interactive web page with a playful "Be My Pookie?" question featuring dynamic animations, growing buttons, and confetti celebration!

## Live Demo

**[Click here to visit the site!](https://saithihanaing1.github.io/BeMyPookie/)**

## Features

-  Interactive "Yes" and "No" buttons with dynamic behavior
-  "Yes" button grows larger with each "No" click
-  "No" button shrinks and displays random messages
-  Confetti celebration when "Yes" is clicked
-  Beautiful gradient background with smooth animations
-  Fully responsive design

##  How to Use

Simply open the page and answer the question! Try clicking "No" a few times and watch what happens...
